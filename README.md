# Claude RTL

قارئ عربي منبثق لويندوز. تنسخ نص عربي من Claude Desktop (أو أي برنامج)،
فيظهر popup بيعرضه مظبوط من اليمين لليسار بتنسيق ماركداون مقروء.

## الشغلانة الأساسية

معظم برامج الديسكتوب بتكسر اتجاه النص العربي — الأرقام تتقلب، علامات
الترقيم تروح آخر السطر، والقوائم والجداول تتعكس. البرنامج ده بيقرأ الحافظة
ويعيد عرض النص في نافذة RTL حقيقية.

## المميزات

- **مراقبة تلقائية للحافظة** — بيشتغل بس لما تنسخ من Claude Desktop (أو من كل
  البرامج لو فعّلت الخيار)، وبيتجاهل النص غير العربي.
- **تحكّم كامل في القراءة** — ستة خطوط عربية، حجم الخط، تباعد الأسطر، وعرض
  السطر (بالـ`ch` عشان يفضل مقروء مهما كان حجم النافذة).
- **إخفاء التشكيل** — بضغطة، لو التشكيل بيشوّش عليك.
- **ثيم فاتح وغامق** + خيار "يتبع النظام".
- **سجل** لآخر ٤٠ نص، بحث فيه، وتنقّل بـ`Alt+←/→`.
- **ماركداون كامل** — عناوين، قوائم متداخلة، قوائم مهام، جداول بمحاذاة،
  اقتباسات، شطب، وبلوكات كود بزر نسخ لكل واحد.
- **اختصارات عامة** تشتغل من أي مكان في ويندوز.
- **مواضع ظهور** — عند المؤشر، آخر مكان استخدمته، أو ملتصق بيمين الشاشة.
- **تثبيت (pin)** يمنع الإخفاء التلقائي لما تسيب النافذة.

## الاختصارات

| الاختصار | الوظيفة |
|---|---|
| `Ctrl+Shift+A` | إظهار/إخفاء آخر نص (من أي مكان) |
| `Ctrl+Shift+D` | تشغيل/إيقاف المراقبة (من أي مكان) |
| `Esc` | إغلاق النافذة |
| `Ctrl` + `+` / `-` | حجم الخط |
| `Ctrl+C` | نسخ النص كامل |
| `Ctrl+H` | السجل |
| `Ctrl+,` | الإعدادات |
| `Ctrl+P` | تثبيت |
| `Alt+←` / `Alt+→` | تنقّل في السجل |

## التشغيل للتطوير

```bat
pip install -r requirements.txt
python claude_rtl.py
```

## البناء

```bat
build.bat
```

بيسطّب المتطلبات، يشغّل الاختبارات، يبني `ClaudeRTL.exe` بـcx_Freeze، وبعدين
المُثبِّت بـ[Inno Setup](https://jrsoftware.org/isdl.php) لو متسطّب.

## الاختبارات

```bat
python tests\test_mdrender.py
```

بتغطي محرك الماركداون وبتشتغل على أي نظام (مافيش اعتماد على ويندوز).

## أين تُحفظ البيانات

`%APPDATA%\ClaudeRTL\`

- `settings.json` — الإعدادات
- `history.json` — السجل (تقدر توقّف حفظه من الإعدادات)

## بنية الملفات

| الملف | المسؤولية |
|---|---|
| `claude_rtl.py` | التشغيل، مراقبة الحافظة، السجل، شريط المهام |
| `ui.py` | الواجهة (HTML + CSS + JS) |
| `mdrender.py` | ماركداون ← HTML، وكشف اتجاه النص |
| `settings.py` | حفظ/تحميل الإعدادات والسجل |
| `winapi.py` | طبقة ويندوز: الحافظة، الشاشات، النوافذ، الاختصارات |
